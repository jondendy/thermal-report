================================================================================
TEMPERATURE CONVERSION DETAILS:
================================================================================

The scripts implement the complete FLIR temperature conversion formula:

1. Extract raw sensor values from embedded metadata
2. Read calibration parameters (Planck R1, R2, B, F, O)
3. Apply atmospheric correction (transmission, humidity)
4. Apply emissivity correction
5. Convert to absolute temperature using Planck's equation:

   T = B / ln(R1/(R2*(Signal+O)) + F)

6. Account for reflected temperature
7. Account for IR window transmission
8. Convert from Kelvin to Celsius

All calculations are vectorized using NumPy for efficiency.
