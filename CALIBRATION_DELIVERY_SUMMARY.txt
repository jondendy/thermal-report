================================================================================
CALIBRATION WORKFLOW:
================================================================================

RECOMMENDED WORKFLOW FOR BUILDING SURVEYS:

1. PREPARATION:
   - Print ArUco marker at exact size (e.g., 50mm × 50mm)
   - Prepare reference objects with known temperatures
   - Set up calibrated thermometer for verification

2. REFERENCE IMAGE:
   - Capture image with ArUco marker visible
   - Include temperature reference object
   - Measure reference temperature accurately
   - Process to create calibration file

3. SURVEY IMAGES:
   - Capture building thermal images
   - ArUco marker not required in every image
   - Process using saved calibration
   - Generate analysis reports

4. ANALYSIS:
   - Compare corrected temperatures across images
   - Identify hot/cold spots
   - Measure dimensions of thermal anomalies
   - Generate comparison reports

TECHNICAL SPECIFICATIONS:
================================================================================

SCALE CALIBRATION:
- Accuracy: ±2% (depends on marker print quality)
- Marker size range: 20mm - 500mm
- Supported dictionaries: DICT_4X4_50 through DICT_7X7_1000
- Measurement units: mm, cm, inches

TEMPERATURE CALIBRATION:
- Single-point correction: Offset only
- Two-point correction: Linear (scale + offset)
- Multi-point correction: Polynomial fitting
- Typical accuracy: ±0.5°C with good references
- Correction persistence: JSON format

COLOR DETECTION:
- Color space: HSV (Hue, Saturation, Value)
- Hue range: 0-179
- Saturation/Value: 0-255
- Minimum patch size: Configurable (default 100 pixels)
- Morphological filtering: Enabled

NORMALIZATION:
- Min-max: Linear scaling to [0, 1]
- Z-score: Standardization to N(0, 1)
- Reference: Custom range mapping
- Preserves NaN/Inf handling

================================================================================
SUPPORT & TROUBLESHOOTING:
================================================================================

Common Issues:

1. ArUco marker not detected
   → Ensure marker is printed at exact size
   → Check lighting and image quality
   → Verify dictionary matches (DICT_6X6_250)

2. Color patch not found
   → Use find_hsv_range() helper to find correct HSV values
   → Adjust hsv_lower and hsv_upper in config
   → Check minimum area threshold

3. Large calibration error
   → Use two-point calibration instead of single-point
   → Verify reference temperatures are accurate
   → Check for camera emissivity settings

4. Integration issues
   → Import both modules in correct order
   → Ensure flirimageextractor is installed
   → Verify OpenCV version supports ArUco (opencv-contrib-python)
